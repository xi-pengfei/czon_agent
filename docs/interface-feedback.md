# 任务反馈与动态角色

本次只改变 React WebUI 的展示，不改变 FastAPI 任务执行、SSE 协议、工具参数、确认流程或小智 MCP。

## 参考与取舍

- 读取和利时项目 `ai_hollysys/frontend/src/components/ExecutionSteps.tsx`、`FlowProgress.tsx` 和 `useLiveReply.ts`：借鉴“当前阶段独立展示、执行记录按需展开、只平滑显示已经收到的文字”。没有连接该项目服务器，也没有修改其代码。
- 查看用户已打开的 openai.fm 页面并读取按钮样式：浅色实体表面、内亮边、内暗边与多层投影。这里只给麦克风、发送、播报、大屏入口和登录按钮加轻微触感，正文区域保持平面。
- 根据用户提供的圆形双眼角色参考，用本项目蓝色绘制 SVG 小角色，不依赖外部图片或新增动画库。

## 行为

默认显示一条当前任务阶段和任务总耗时；命令、参数、工具返回与逐步耗时放在“执行详情”。需要业务确认时自动展开，确认按钮和原始操作内容仍可查看。阶段描述来自真实工具状态，不把工具结束直接解释成业务成功。

公开回复平滑显示已经收到的增量；历史回复、替换后的最终回复及停止/失败状态立即显示完整文字。不生成假的思考内容，不用固定计时假装完成进度。

角色：空闲时眨眼、工作时侧看、录音时专注、实际播放音频时说话、处理结束时弯眼、异常或待确认时提醒。状态变化时播放短动画，最长不到4秒，随后停留在该表情；操作系统开启“减少动态效果”时不启动新角色动画。语音播报只是开启但没有播放时，不显示说话表情。

手机保留44px麦克风与发送按钮；同一组件也用于电脑及大屏。无需重启后端，刷新网页即可加载新构建。

前端构建及14项自动测试通过，其中新增检查：默认折叠技术步骤、确认操作保持展开、停止后不再显示工具仍在运行。
隔离测试服务中验证默认阶段、详情展开、320/390px无横向溢出、44px触控按钮及大屏切换。未重启实际业务服务。
