# 公司经营数据：讲解与提问手册

## 数据与实现

此数据集为现场展示编写的虚构样例，不含真实企业客户数据。对外技能名为「公司经营数据」，平常回答不必逐句加“演示”；问来源和真实性时应如实说明。当前范围只有销售订单，不包含公司的完整财务经营情况。

本技能没有使用数据库服务，数据保存在 `assets/sales.csv`。CSV 是类似 Excel 的文本表格，只有 12 行商品明细，8 个订单号。大模型把自然语言转为查询参数，一次执行 Python 标准库脚本，读一次表格、过滤、精确计算金额，然后把结构化结果简短说出来。无网络查询、无模型嵌套调用、无数据写入。CzON 本身的账号、会话等保存在 SQLite，与本技能数据分开。

数据日期为 2026 年 11 月 1 日至 14 日，金额人民币，价格含税。销售额按订单金额统计，包括已发货和待发货，不代表已收款或会计收入。修改 CSV 即可更新本技能的数据；保持字段和同一订单的基本信息一致。

## 可以直接问的话

不用念英文工具名，也不用先说技能名：

1. “看一下公司经营数据，总共有多少笔订单？” → 8笔，18,400元。
2. “北京有几笔订单？” → 4笔。
3. “北京这几单都买了什么？分别多少钱？” → XS001、XS003、XS005、XS008，见上表。
4. “其中还有哪些没发货？” → 继承北京条件，3笔，4,900元。
5. “上海和深圳分别卖了多少钱？” → 可一次查 cities 后取上海4,200元、深圳6,500元。
6. “哪个城市销售额最高？” → 北京7,700元。
7. “哪个客户买得最多，按金额算？” → 浦江机电和南海设备并列，各4,200元。
8. “华北智造买过什么？” → 两笔，温度传感器10件、工业网关2件、电源适配器20件，合计3,800元。
9. “哪个商品销量最多？” → 温度传感器40件。
10. “哪个商品销售额最高？” → 工业网关7,200元。注意它与销量最高商品不同。
11. “北京的工业网关卖了多少？” → 5件，4,000元，涉及2笔订单。
12. “查一下 XS001 的订单明细。” → 传感器10件、网关2件，总额2,800元。
13. “2026年11月1号到7号卖了多少钱？” → 4笔订单，10,400元。
14. “本月销售额多少？” → 按服务器上海时区的实际当前月份筛选；不是2026年11月就没有匹配数据，不应继续报18,400元。
15. “北京利润多少？收到多少钱？仓库还有多少？” → 当前数据没有利润、回款或库存，不能编造。

## 小智如何找到这个技能

这个 Skill 在 CzON 里面，MCP 对外仍提供 `business_request`，没有为每个 Skill 注册单独的 MCP 工具。小智调用 business_request 后，由 CzON 自动选择本技能。

小智「角色说明」可加入下面这段（本次仅提供文本，没有自动修改云端角色）：

> 用户提出企业业务查询、数据分析或业务操作需求时，调用 business_request，完整转交原始需求，不自行限定具体技能或数据来源。连续追问沿用返回的 conversation_id，保留已明确的查询条件。根据工具返回回答；缺少必要信息时向用户确认，没有对应能力时如实说明，不编造结果。调用超时不要自动重复提交。普通闲聊直接回答。

小智入口保持通用，由 CzON 按需求和权限选择技能。本技能只用于已明确使用本地展示样例的场景，不能作为所有经营问题的默认数据源；存在真实账套和样例等多个来源而用户未指明时，应先确认来源。

如果说自然问句没有出现 CallToolRequest，说明小智尚未转交到业务入口，应检查该智能体工具启用状态与角色说明。首次排障可临时说“请调用 business_request，查询北京订单数量”；这不是正常使用必须念的口令。
