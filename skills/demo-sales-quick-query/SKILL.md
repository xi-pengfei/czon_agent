# 公司经营数据

## 数据边界

数据来自本技能 `assets/sales.csv`，是为现场展示编写的样例，不是客户真实账套；保留返回的 `is_demo` 和 `source` 元数据。面向用户的名称和日常口头回复不必重复“演示”二字，也不虚构公司名称。问数据来源或是否真实时，如实说明是本地样例，不能声称已连接金蝶或客户生产数据库。

仅在对话已明确使用本地展示数据时使用；不能作为所有经营数据问题的默认来源。用户未指明来源且可能涉及真实业务时，先确认要查本地展示数据还是实际账套，不把样例数字当成企业实际经营结果。

数据范围为 **2026-11-01 至 2026-11-14**。无日期限定时查询全部记录；“本月”传 `--month current`，绝不把样例月份冒充当前月份。其他月份无数据就如实回答。金额为所选订单明细的含税金额合计（数量×含税单价），不是回款、利润或财务确认收入。订单数按订单号去重；商品筛选只累计匹配商品明细的金额。

## 一次查询

从项目根目录执行一次固定脚本，依据问题选择参数，不需要先读脚本或其他技能：

```bash
python skills/demo-sales-quick-query/scripts/query.py --view overview
```

| 用户需求 | 参数示例 |
| --- | --- |
| 总销售额、订单数 | `--view overview` |
| 北京几单、多少钱 | `--city 北京` |
| 北京订单内容、分别多少钱 | `--view orders --city 北京` |
| 某笔订单明细 | `--order-id XS001` |
| 各城市销售额、城市排名 | `--view cities` |
| 各客户销售额、客户排名 | `--view customers` |
| 商品销售额、件数、排名 | `--view products` |
| 华北智造买过什么 | `--view orders --customer 华北智造` |
| 北京哪些订单未发货 | `--view orders --city 北京 --status 待发货` |
| 本月销售额 | `--month current` |
| 指定月份 | `--month 2026-11` |
| 11月1日至7日 | `--start 2026-11-01 --end 2026-11-07` |
| 北京工业网关销售额 | `--city 北京 --product 工业网关` |

可组合 city、customer、product、order-id、status 与日期条件；month 和 start/end 不同时用。参数值用安全 shell 引号，不能把用户整句直接拼成命令。城市“北京市”等可去除行政后缀后匹配“北京”。订单号统一 XS 加三位数字，如“第一单/一号订单”明确指 XS001 时使用 XS001；不明确的序号先澄清。

`products/cities/customers` 的 groups 按金额降序。问销量最多时按 quantity 比较，问金额最高按 amount 比较，两者不同；并列要保留。amount/revenue 为十进制字符串，不能按字符串字典序比较金额。追问“这几单”“其中未发货”时继承对话中已经明确的城市、客户、日期条件，再查询一次；不明确就追问。

直接用 summary 或 data 回答，只讲被问到的指标，通常一到三句话。订单列表按用户要求列全，不能漏掉其中一笔。不要念 JSON、内部路径、计时或无关字段；数量、单号、金额以结果为准，不从示例或记忆中补数字。

每次仅读取一次本地 CSV，无网络、无额外依赖、无密钥、无写操作。脚本失败时说明没有有效结果。其他业务如库存、成本、利润、收款和创建订单不支持。需要了解完整数据和问法时才阅读 `references/presenter-guide.md`。
